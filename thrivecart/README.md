# Simply Digital — ThriveCart checkout kit

A reusable, brand-consistent skin for Simply Digital ThriveCart checkouts
(burgundy / cream / gold, Seriously Nostalgic + Bodoni Moda + Inter). One
shared framework styles every product; each product only supplies its own
copy via a small config.

## How it's structured

```
thrivecart/
├── framework/                 ← shared, product-agnostic (rarely edit)
│   ├── framework.css          full checkout + success skin
│   ├── engine.js              injects header/hero/footer, hides address,
│   │                          scrolls CTA buttons — reads SDS_CONFIG
│   └── build.sh               assembles each product's paste-ready files
└── products/
    └── <product-name>/
        ├── config.js          ← EDIT: logo/tagline/footer + hero copy + flags
        ├── sections.html      ← EDIT: checkout content blocks (copy)
        ├── success-card.html  ← EDIT: the "You've Got It!" message
        └── dist/              ← GENERATED by build.sh (paste these)
            ├── checkout-tracking.html
            └── success-block.html
```

**Never edit `dist/` by hand** — it's regenerated. Edit `config.js` /
`sections.html` / `success-card.html`, then run the build.

## Build

```
bash framework/build.sh                                # all products
bash framework/build.sh shopify-conversion-roadmap     # just one
```

## Applying a product in ThriveCart

1. **Checkout → Design:** pick the same template/layout as the other
   products (two-column cart), so the block structure lines up.
2. **Checkout → Tracking → "All pages":** paste
   `products/<name>/dist/checkout-tracking.html` (replace any previous
   version — only ONE copy should run). This brings the whole skin +
   the injected header/hero/footer bands + coupon/summary/bump styling +
   the CTA scroll + (optionally) the address hide.
3. **Checkout editor:** add a Custom HTML element for each block in
   `products/<name>/sections.html` (What's-inside → left column;
   Introducing / What-you'll-get / About → above the cart form).
4. **Success page:** add a Custom HTML element and paste
   `products/<name>/dist/success-block.html`.

The header/hero/footer are **injected** (attached to `<html>` so they run
full-width regardless of ThriveCart's padded columns) — do not also place
them as editor blocks.

## Adding a new product

1. `cp -r products/shopify-seo-simplified products/<new-name>`
2. Edit `config.js` (hero copy, `hideAddress` flag), `sections.html`
   (block copy), and `success-card.html` (message).
3. `bash framework/build.sh <new-name>`
4. Apply in ThriveCart per the steps above.

## config.js reference

| Field | What it controls |
|---|---|
| `logoUrl`, `tagline` | Header bar (shared across products) |
| `footer.brand`, `footer.links[]` | Footer copyright + links (open in new tab) |
| `hideAddress` | `true` = fill placeholder values into country/state/postcode then hide them (for offers that must not collect an address). Test a purchase after enabling. |
| `hero.eyebrow/title/subtitle/meta[]/ctaLabel` | The burgundy hero band + its "get access" button |

## Notes / gotchas baked in

- **Full-width bands** are injected to `<html>`, not `<body>` — ThriveCart
  caps/centres `<body>`, which pushed bands "to one side".
- **Address hide** fills the fields first (dispatching input/change) then
  hides them; hiding empty required fields silently blocks Complete Order.
- **CTA buttons** scroll via JS (`scrollIntoView`) on every click — a
  plain `#anchor` stops working once the URL hash already matches.
- **Footer / About links** need `!important` colours to beat ThriveCart's
  default blue; the built-in ThriveCart footer is hidden.
- **Fonts:** Google Fonts + the Seriously Nostalgic face from
  `offers.simplydigitalshops.com`; falls back to Bodoni Moda if blocked.

Brand tokens: burgundy `#5a002a` · red `#950d20` · gold `#c7a35a` ·
cream `#e8e4d3` · cream-light `#f5f2e8` · ink `#1a1410`.
