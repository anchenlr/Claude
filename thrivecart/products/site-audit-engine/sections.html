Why bother

Audits are one of the best ways to start a client conversation, but doing one by hand for every prospect takes hours, so most of us skip them or send something generic. The Site Audit Engine does the legwork. You set up your criteria and your branding once, then run an audit on any site by dropping in a URL.

What you get

Everything you need to run audits on demand

  • A ready-to-import Make automation: URL in, page and speed data gathered, audit drafted
  • A starter audit skill so it works on day one
  • A builder skill that creates your own audit skill and branded report template from your criteria and brand details
  • An Airtable template to store your audits

Who it's for

Web designers, developers and freelancers who want to open client conversations with something useful, without spending hours on each audit.

What you'll need

A Make account and your own Claude API key. You'll pay those directly for usage, so there's no markup on top.

Works with other tools via API or webhook too.
